# Epistles of Wisdom · Complete English Translation

Read and search all 111 Druze Epistles of Wisdom (*Rasāʾil al-Ḥikma*, رسائل الحكمة) in English. This edition is based primarily on the [seventh Arabic edition](https://archive.org/download/rasail-al-hikma/%D8%AC%D9%85%D9%8A%D8%B9%20%D8%B1%D8%B3%D8%A7%D8%A6%D9%84%20%D8%A7%D9%84%D8%AD%D9%83%D9%85%D8%A9.pdf#page=3), published by Dār li-Ajl al-Maʿrifa in 1986, with the title-page imprint “Diyār ʿAql—Lebanon” (ديار عقل - لبنان).
